# 开机动画模块

用 KernelSU 模块替换 ColorOS 的开机动画，支持「全屏自定义视频」（中间清晰、上下用同画面模糊压暗填充）。

## 为什么需要模块

ColorOS 的 `bootanimation.zip` 在只读分区（erofs），`/system` 不能直接改，`overlay` 也不生效。可行办法是**开机早期（post-fs-data）用 bind mount** 把自定义 zip 挂到系统动画路径上。

## 关键技术点

### 1. ColorOS 的私有 desc 格式

AOSP 的格式是 `W H FPS` + `p 次数 暂停 目录`，**ColorOS 改成了**：

```
g <宽> <高> <offsetX> <offsetY> <fps>
p <次数> <暂停秒> <目录名>
```

- `g` 行第一个数字是**画面区域宽**，第二是**高**（不是整屏分辨率）
- `offsetX/offsetY` 是偏移（早期用 0 900 做过居中错位实验）
- 全屏动画区域示例：`g 1264 2780 0 0 15`（整块屏幕）

### 2. 全屏「中间清晰 + 上下模糊」的做法

开机动画区域通常是一条横向条带（约 1264×620）。要做成整屏：

1. 取原视频中间 **1264×620** 区域，缩放后作为清晰主体
2. 同画面放大到 1264×2780、高斯模糊、压暗，作为上下填充
3. 两者拼成 1264×2780 的整屏帧
4. 15 fps、4 秒、JPEG 帧，整包约 5~7 MB

### 3. 挂载时机

`post-fs-data.sh` 里**后台循环重试**挂载（最多 60 次，每次 1 秒），不阻塞开机：

```sh
SRC="$MODDIR/bootanimation.zip"
T1=/my_product/media/bootanimation/bootanimation.zip
T2=/mnt/vendor/my_product/media/bootanimation/bootanimation.zip
```

两个路径都试：不同 OTA 版本系统分区挂载点不同。日志写到 `/data/local/tmp/bootanim.log`。

## 目录与文件

| 文件 | 用途 |
|---|---|
| `module/module.prop` | KernelSU 模块信息（id / 名称 / 版本 / 描述） |
| `module/post-fs-data.sh` | 开机早期后台 bind mount，替换系统动画 |
| `bootanimation.zip` | 最终动画包（内含 desc.txt 与 part0/ 帧） |
| `desc.txt` | 动画描述（`g` / `p` 行），也在 zip 内一份 |

## 构建流程

```bash
# 1. 从视频截 4 秒，取中间区域做清晰主体
ffmpeg -ss 0 -t 4 -i wallpaper.mp4 -vf "scale=1264:-2,crop=1264:620" -r 15 frames/part0/frame_%04d.jpg

# 2. 生成全屏版：中间清晰 + 上下模糊压暗（见构建脚本思路）
# 3. 生成 desc.txt（ColorOS 私有格式 g 行）
# 4. 打包（注意：zip 内不要多一层目录，desc.txt 在根）
zip -0 -r bootanimation.zip desc.txt part0

# 5. 塞进 KernelSU 模块目录，打包刷入
```

> 注意：帧必须用 **存储（store，-0）** 方式打包，压缩会导致开机时解码过慢甚至黑屏。

## 版本演进（踩坑）

| 版本 | 变化 | 结果 |
|---|---|---|
| v0.1~v0.3 | 横条动画、诊断包 | 能替换，但只显示横条 |
| v0.4~v1.0 | 鲸鱼系列，尝试不同缩放 | 效果逐版变好 |
| v1.3 | overlay 方案 | **失败**：erofs 不支持 overlay |
| v1.5~v1.6 | 视频转帧、调整 fps | 流畅度改善 |
| v2.0 | 全屏 + 上下模糊填充 | **基本可用** |
| v2.1 | 全屏效果定稿（g 1264 2780 0 0） | **主人评价「全屏效果简直完美」** |

## 常见问题

- **黑屏 / 停在旧动画**：mount 没成功，看 `/data/local/tmp/bootanim.log` 的 `result=` 行
- **动画只显示一条**：`g` 行的宽高写错（要填画面区域，不是屏幕分辨率）
- **卡顿**：帧率太高或用了压缩打包，降到 15 fps + `zip -0`
- **OTA 后失效**：系统分区路径变了，检查 `T1`/`T2` 是否存在
