# 手机控制模块

在电脑上（或通过聊天让 agent）远程控制手机：设闹钟、导航、打开 App、点按、输入、截屏、执行 shell。

## 为什么这么做

常见的手机自动化依赖 ADB + USB 线（要一直插着）或云手机（要花钱）。这里的方案是：

- **不插线**：走公网消息通道（ntfy.sh）
- **不需要公网 IP**：手机主动订阅，电脑只管发
- **有鉴权**：每条指令带 HMAC 签名 + 时间戳
- **能开机自启**：KernelSU 模块在开机时以 root 拉起 Termux 里的执行器

## 架构

```
电脑 CLI (phone.mjs)
   │  ① 生成 {id, tool, args, ts}
   │  ② base64 + sha256(payload+KEY) 签名
   ├─► POST https://ntfy.sh/<topic>-cmd
   │
   │            手机 Termux (dsh-agent.sh, root)
   │            ③ 订阅 <topic>-cmd，收到后校验签名/时间窗
   │            ④ 执行对应命令（am / input / screencap / su …）
   └─◄ ⑤ POST 回执到 <topic>-res（格式 `id|结果`）
   ⑥ CLI 匹配 id 后打印结果，超时 60 秒
```

## 组件

| 文件 | 跑在哪 | 作用 |
|---|---|---|
| `pc/phone.mjs` | 电脑 | CLI：拼参数 → 签名 → 发指令 → 订阅回执 → 打印结果 |
| `pc/phone-ui.mjs` | 电脑 | UI 自动化：`uiautomator dump` 拿 XML → 按文字找控件坐标 → 下发 tap |
| `phone/dsh-agent.sh` | 手机 | 常驻执行器：订阅、验签、执行、回执；单实例锁防止重复 |
| `modules/dsh-phone-agent-v1.0.7.zip` | 手机 | KernelSU 模块：开机以 root 执行 `dsh-agent.sh` |

## 安装

1. **手机**：装 Termux，在 `~` 放好 `dsh-agent.sh`（把 `YOUR_NTFY_TOPIC` / `YOUR_HMAC_KEY` 换成自己的）
2. **手机**：安装 `modules/dsh-phone-agent-v1.0.7.zip`（KernelSU → 模块 → 从本地安装），重启
3. **电脑**：在 `phone-control/pc/` 同级准备 `topic.txt` 与 `hmac.key`（与手机端一致）
4. **验证**：`node phone.mjs alarm hour=7 minute=20 label=测试`

## 可用指令

| tool | 参数 | 说明 |
|---|---|---|
| `alarm` | `hour` `minute` `label` | 设闹钟（`am start SET_ALARM`，静默） |
| `nav` | `q` | 百度地图导航（失败退回系统 geo） |
| `open` | `pkg` | 按包名打开 App |
| `tap` | `x` `y` | 点击坐标 |
| `text` | `text` | 输入文字（配 ADBKeyboard） |
| `key` | `code` | 按键（HOME / BACK 等） |
| `swipe` | `x1 y1 x2 y2` | 滑动 |
| `shot` | — | 截屏并取回 |
| `notify` | — | 读通知 |
| `bright` | `level` | 调亮度 |
| `camera` / `call` | — / `number` | 开相机 / 拨号 |
| `shell` | `cmd` | 执行任意 shell（最高风险） |

## 安全设计

- **签名**：`sha256(base64(payload) + KEY)`，密钥只在两端保存，不走网络
- **时间窗**：指令 `ts` 超过 300 秒直接拒绝（防重放）
- **单实例锁**：避免多个执行器同时响应、重复执行
- **权限**：执行器以 root 跑，所以每条指令都视为高危；`shell` 慎用

## 踩坑记录

1. **`LD_LIBRARY_PATH` 污染**：root 下如果全局设了 Termux 的 lib 路径，`screencap`、`am` 等系统程序会加载错库直接崩。做法：只在调用 Termux 的 `curl` 时临时设置（见 `curl_t()`）。
2. **`uiautomator dump` 在 KernelSU 下失败**：需要切回 shell 域：
   `su -Z u:r:shell:s0 2000 -c "uiautomator dump /sdcard/ui.xml"`
3. **中文字符输入**：系统 `input text` 不支持中文，需装 ADBKeyboard 并临时切换输入法。
4. **ntfy 免费通道**：消息保留时间短，回执必须及时订阅；CLI 先订阅再发送，避免漏接。
